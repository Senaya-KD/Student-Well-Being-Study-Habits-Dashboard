# 🎓 Student Well-Being & Study Habits Dashboard

This interactive dashboard was developed using **Dash**, **Plotly**, and **Pandas** to analyze university students’ well-being and study habits.  
It visualizes relationships between factors like **stress**, **sleep quality**, **motivation**, and **study hours** and their impact on **academic performance (GPA)**.

---

### Features
- Interactive charts for GPA vs stress, sleep, and study hours  
- KPI cards for total students, average GPA, and satisfaction %  
- Dynamic filters by program, gender, and stress band  
- Drill-down data table for detailed analysis  
- Clean and responsive layout with CSS  

---

###  Dataset
The dataset (`clean_survey.csv`) was created from survey responses collected from students and cleaned for analysis.
