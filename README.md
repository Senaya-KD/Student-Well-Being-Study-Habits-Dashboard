# 🎓 Student Well-Being & Study Habits Dashboard

This is an interactive dashboard built using **Dash**, **Plotly**, and **Pandas** to analyze university students' well-being and study habits.  
It visualizes how factors such as **stress, sleep, motivation**, and **study routines** impact **academic performance (GPA)**.

---

## 📊 Features
- Dynamic charts for GPA vs stress, sleep, and study hours  
- KPI cards for total students, average GPA, and satisfaction %  
- Interactive filters by program, gender, and stress band  
- Clean and responsive design with CSS  

---

## 🛠️ Technologies Used
- **Python**
- **Dash & Plotly**
- **Pandas**
- **VS Code**

---

## 📁 Dataset
Located in `clean_survey.csv`  
Contains anonymous student survey responses collected for coursework.
